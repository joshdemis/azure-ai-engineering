# Notes

Weekly learning notes captured throughout the journey. One file per week keeps
progress visible and searchable over time.

## Conventions

- One file per learning path, named `NN-topic.md`, where `NN` matches the path number
  in [`../docs/roadmap.md`](../docs/roadmap.md) and the lab folder in
  [`../labs/`](../labs/).
- A path spanning several modules may carry a module suffix, for example
  `03-aks-deploy.md`.
- Start each note from the [note template](TEMPLATE.md).
- Link notes to their matching lab under [`../labs/`](../labs/) and to the relevant week
  in [`../docs/study-plan.md`](../docs/study-plan.md).
